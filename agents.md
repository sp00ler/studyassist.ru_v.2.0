# AGENTS.md

Правила для Codex в этом репозитории:

1. Работай только в ветках codex/*.
2. Никогда не меняй main напрямую.
3. Никогда не меняй deploy/vds напрямую.
4. Любые изменения готовь через reviewable diff.
5. После выполнения задачи предлагай pull request из codex/* в deploy/vds.
6. Делай минимальные и точечные изменения.
7. Не удаляй файлы без явной необходимости.
8. Перед изменениями сначала найди связанные файлы и кратко объясни план.
9. Если меняется конфиг, роутинг, auth, upload или env-логика — укажи это отдельно.
10. Не трогай секреты, токены, пароли, .env.
